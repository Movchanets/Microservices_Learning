# 3.0 — Inventory & Cart Contracts

> **Ref**: [plans/05-messaging-sagas.md](../../plans/05-messaging-sagas.md) · [plans/02-domain-decomposition.md](../../plans/02-domain-decomposition.md)

## Goal
Create the shared integration contracts for the Inventory and Cart services in `BuildingBlocks.SharedContracts`. This includes DTOs, Commands, and Events.

## Prerequisites
- BuildingBlocks.SharedContracts project exists

## Steps

### Step 1: Create Shared DTOs

File: `src/BuildingBlocks/SharedContracts/Dtos/OrderItemContract.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Dtos;

public record OrderItemContract(
    string Sku,
    int Quantity);
```

### Step 2: Create Cart Integration Events

File: `src/BuildingBlocks/SharedContracts/Events/Cart/OrderSubmittedEvent.cs`
```csharp
using BuildingBlocks.SharedContracts.Dtos;

namespace BuildingBlocks.SharedContracts.Events.Cart;

public record OrderSubmittedEvent(
    Guid CorrelationId,
    string BuyerId,
    List<OrderItemContract> Items,
    DateTime Timestamp);
```

### Step 3: Create Inventory Commands

File: `src/BuildingBlocks/SharedContracts/Commands/Inventory/ReserveInventoryCommand.cs`
```csharp
using BuildingBlocks.SharedContracts.Dtos;

namespace BuildingBlocks.SharedContracts.Commands.Inventory;

public record ReserveInventoryCommand(
    Guid CorrelationId,
    Guid OrderId,
    List<OrderItemContract> Items);
```

File: `src/BuildingBlocks/SharedContracts/Commands/Inventory/CancelReservationCommand.cs`
```csharp
using BuildingBlocks.SharedContracts.Dtos;

namespace BuildingBlocks.SharedContracts.Commands.Inventory;

public record CancelReservationCommand(

```
