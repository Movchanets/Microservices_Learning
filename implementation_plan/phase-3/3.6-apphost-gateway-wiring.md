# 3.6 — AppHost & Gateway Wiring

> **Ref**: [plans/06-api-gateway-bff.md](../../plans/06-api-gateway-bff.md)

## Goal
Integrate the newly created `Inventory.API` and `Cart.API` into the Aspire AppHost for orchestration, and configure routing in the YARP API Gateway.

## Prerequisites
- Sub-plans 3.4 and 3.5 completed
- Both `Inventory.API` and `Cart.API` are in the solution

## Steps

### Step 1: Add Project References to AppHost

```powershell
dotnet add src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj reference src/Microservices/Inventory/Inventory.API/Inventory.API.csproj
dotnet add src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj reference src/Microservices/Cart/Cart.API/Cart.API.csproj
```

### Step 2: Configure Aspire Orchestration

Edit: `src/Aspire/Marketplace.AppHost/AppHost.cs`

1. Uncomment/add the `Inventory.API` project:
```csharp
var inventoryApi = builder.AddProject<Projects.Inventory_API>("inventory-api")
    .WithReference(inventoryDb)
    .WaitFor(inventoryDb)
    .WithReference(messaging)
    .WaitFor(messaging);
```

2. Register the `Cart.API` project:
```csharp
var cartApi = builder.AddProject<Projects.Cart_API>("cart-api")
    .WithReference(redis)
    .WaitFor(redis)
    .WithReference(messaging)
    .WaitFor(messaging);
```

3. Update the `gateway` reference to point to the new services:
```csharp
var gateway = builder.AddProject<Projects.ApiGateway>("api-gateway")
    // ... existing references ...
    .WithReference(inventoryApi)
    .WaitFor(inventoryApi)
    .WithReference(cartApi)
    .WaitFor(cartApi)
    // ... existing config ...
```

4. Add to Scalar API Reference:
```csharp
scalar
    // ... existing references ...
    .WithApiReference(inventoryApi)
    .WithApiReference(cartApi)
    .WaitFor(inventoryApi)
    .WaitFor(cartApi);
```

### Step 3: Configure YARP Routing

Edit: `src/Gateways/ApiGateway/appsettings.json` (or `appsettings.Development.json`) to add the new routes and clusters.

```json
{
  "ReverseProxy": {
    "Routes": {
      "inventory-route": {
        "ClusterId": "inventory-cluster",
        "Match": {
          "Path": "/api/inventory/{**catch-all}"
        }
      },
      "cart-route": {
        "ClusterId": "cart-cluster",
        "Match": {
          "Path": "/api/cart/{**catch-all}"
        }
      }
    },
    "Clusters": {
      "inventory-cluster": {
        "Destinations": {
          "destination1": {
            "Address": "https+http://inventory-api"
          }
        }
      },
      "cart-cluster": {
        "Destinations": {
          "destination1": {
            "Address": "https+http://cart-api"
          }
        }
      }
    }
  }
}
```

## Verification
- Start the AppHost: `dotnet run --project src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj`
- Ensure the Aspire dashboard displays `inventory-api` and `cart-api` as running.
- Ensure the APIs are reachable via the Gateway URL (`/api/inventory/...` and `/api/cart/...`).

## Done When
- [ ] `Inventory.API` and `Cart.API` are orchestrated via Aspire.
- [ ] Database and Redis connections are injected successfully.
- [ ] YARP routes the incoming requests to both services.
