# 5.0 — Notification.Worker Project Setup

> **Ref**: [plans/07-realtime-signalr.md](../../plans/07-realtime-signalr.md)

## Goal
Create the `Notification.Worker` project as an ASP.NET Core Worker Service that hosts a SignalR Hub. This is NOT a Minimal API — it has no REST endpoints, only the SignalR hub at `/hubs/notifications`.

## Prerequisites
- Phase 4 completed (integration contracts exist in SharedContracts)

## Steps

### Step 1: Create the project

```powershell
dotnet new worker --name Notification.Worker --output src/Microservices/Notification/Notification.Worker --framework net10.0
dotnet sln Marketplace.slnx add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj reference src/BuildingBlocks/SharedContracts/BuildingBlocks.SharedContracts.csproj
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj reference src/Aspire/Marketplace.ServiceDefaults/Marketplace.ServiceDefaults.csproj
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj package MassTransit.RabbitMQ --version 8.3.5
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj package Microsoft.AspNetCore.SignalR.StackExchangeRedis --version 10.0.8
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj package Aspire.RabbitMQ.Client --version 13.3.2
dotnet add src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj package Microsoft.Extensions.Hosting --version 10.0.8
```

### Step 2: Create folder structure

```powershell
mkdir -p src/Microservices/Notification/Notification.Worker/Hubs
mkdir -p src/Microservices/Notification/Notification.Worker/Consumers
mkdir -p src/Microservices/Notification/Notification.Worker/Models
```

### Step 3: Add to solution

The project is added via `dotnet sln` in Step 1. Verify it appears in `Marketplace.slnx` under a `Notification` folder.

### Step 4: Create stub files

Create empty placeholder files (implementation in sub-plans 5.1-5.3):
- `Hubs/NotificationHub.cs`
- `Hubs/UserIdProvider.cs`
- `Models/OrderUpdateMessage.cs`
- `Consumers/OrderCompletedConsumer.cs`
- `Consumers/OrderCancelledConsumer.cs`
- `Consumers/PaymentFailedConsumer.cs`
- `Consumers/InventoryReservationFailedConsumer.cs`

## Verification
```powershell
dotnet build src/Microservices/Notification/Notification.Worker/Notification.Worker.csproj
```

## Done When
- [ ] Project created and added to solution
- [ ] All package and project references configured
- [ ] Folder structure created
- [ ] Project builds with 0 errors
