# 2.0 — Catalog Integration Event Contracts

> **Ref**: [plans/05-messaging-sagas.md](../../plans/05-messaging-sagas.md) · [plans/02-domain-decomposition.md](../../plans/02-domain-decomposition.md) · [implementation_plan/phase-2-catalog-search.md](../phase-2-catalog-search.md)

## Goal
Define integration event contracts for Catalog ↔ Search communication in `BuildingBlocks.SharedContracts`. These are the **public API** of the Catalog bounded context consumed by Search.API.

## Prerequisites
- Phase 0 completed (SharedContracts project exists with `Events/` and `Commands/` folders)

## ⚠️ Rules (from architecture docs)
- **Records only** — flat, immutable data contracts
- **NO** domain entities, **NO** business logic
- **NO** EF Core or infrastructure packages
- Namespace: `BuildingBlocks.SharedContracts.Events.Catalog`

## Steps

### Step 1: Create the Catalog events namespace folder

```powershell
New-Item -ItemType Directory -Force -Path "src/BuildingBlocks/SharedContracts/Events/Catalog"
```

### Step 2: Create `ProductCreatedEvent.cs`

File: `src/BuildingBlocks/SharedContracts/Events/Catalog/ProductCreatedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Catalog;

/// <summary>
/// Published by Catalog.API when a new product is created.
/// Consumed by Search.API to index the product in Elasticsearch.
/// </summary>
public sealed record ProductCreatedEvent(
    Guid ProductId,
    string Name,
    string Description,
    decimal Price,
    string Currency,
    string Sku,
    Guid CategoryId,
    string CategoryName,
    List<string> Tags,
    string? ImageUrl,
    Guid SellerId,
    DateTime CreatedAt);
```

### Step 3: Create `ProductUpdatedEvent.cs`

File: `src/BuildingBlocks/SharedContracts/Events/Catalog/ProductUpdatedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Catalog;

/// <summary>
/// Published by Catalog.API when product details are modified.
/// Consumed by Search.API to update the Elasticsearch document.
/// </summary>
public sealed record ProductUpdatedEvent(
    Guid ProductId,
    string Name,
    string Description,
    decimal Price,
    string Currency,
    string Sku,
    Guid CategoryId,
    string CategoryName,
    List<string> Tags,
    string? ImageUrl,
    bool IsActive,
    DateTime UpdatedAt);
```

### Step 4: Create `ProductDeletedEvent.cs`

File: `src/BuildingBlocks/SharedContracts/Events/Catalog/ProductDeletedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Catalog;

/// <summary>
/// Published by Catalog.API when a product is soft-deleted.
/// Consumed by Search.API to remove the document from Elasticsearch index.
/// </summary>
public sealed record ProductDeletedEvent(
    Guid ProductId,
    DateTime DeletedAt);
```

### Step 5: Create `ProductPriceChangedEvent.cs`

File: `src/BuildingBlocks/SharedContracts/Events/Catalog/ProductPriceChangedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Catalog;

/// <summary>
/// Published by Catalog.API when product price is specifically changed.
/// Used downstream by Inventory/Cart for price validation.
/// </summary>
public sealed record ProductPriceChangedEvent(
    Guid ProductId,
    decimal OldPrice,
    decimal NewPrice,
    string Currency,
    DateTime ChangedAt);
```

### Step 6: Remove `.gitkeep` from Events folder (if still present)

```powershell
Remove-Item src/BuildingBlocks/SharedContracts/Events/.gitkeep -ErrorAction SilentlyContinue
```

## Verification

```powershell
dotnet build src/BuildingBlocks/SharedContracts/BuildingBlocks.SharedContracts.csproj
```

Must compile with zero errors. **No new NuGet packages required** — these are plain records.
