# 0.1 — Create Solution File & Directory Skeleton

> **Ref**: [plans/04-monorepo-structure.md](../../plans/04-monorepo-structure.md) · [implementation_plan/phase-0-foundation.md](../phase-0-foundation.md)

## Goal
Create the `Marketplace.sln` solution file and the empty directory structure for the monorepo.

## Steps

### Step 1: Create directory skeleton

Run from the repository root (`d:\code\Microservices`):

```powershell
# Create all directories
New-Item -ItemType Directory -Force -Path `
  "src/Aspire/Marketplace.AppHost", `
  "src/Aspire/Marketplace.ServiceDefaults", `
  "src/Gateways/ApiGateway", `
  "src/Microservices/Identity", `
  "src/Microservices/Catalog", `
  "src/Microservices/Search", `
  "src/Microservices/Inventory", `
  "src/Microservices/Cart", `
  "src/Microservices/Ordering", `
  "src/Microservices/Payment", `
  "src/Microservices/StoreManagement", `
  "src/Microservices/Media", `
  "src/Microservices/Notification", `
  "src/BuildingBlocks/SharedContracts", `
  "src/BuildingBlocks/Infrastructure", `
  "src/web", `
  "tests/UnitTests", `
  "tests/IntegrationTests", `
  "tests/E2ETests"
```

### Step 2: Create the solution file

```powershell
dotnet new sln --name Marketplace --output .
```

This creates `Marketplace.sln` in the repository root.

### Step 3: Create a `.gitignore`

```powershell
dotnet new gitignore
```

### Step 4: Create a `global.json`

Create the file `global.json` at the repository root with:

```json
{
  "sdk": {
    "version": "10.0.100",
    "rollForward": "latestFeature"
  }
}
```

## Verification

```powershell
# Confirm solution file exists
Test-Path ./Marketplace.sln  # Should return True

# Confirm directory structure
Get-ChildItem -Recurse -Directory src/ | Select-Object FullName
```

## Done When
- [x] `Marketplace.sln` exists at repo root
- [x] All directories from the monorepo layout exist under `src/` and `tests/`
- [x] `global.json` pins .NET 10 SDK
- [x] `.gitignore` for .NET projects exists
