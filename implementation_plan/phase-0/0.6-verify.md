# 0.6 — Wire Solution, Build & Verify

> **Ref**: [plans/04-monorepo-structure.md](../../plans/04-monorepo-structure.md) · [implementation_plan/phase-0-foundation.md](../phase-0-foundation.md)

## Goal
Ensure all 4 projects are in the solution, the full solution builds, and Aspire dashboard launches with infrastructure containers.

## Prerequisites
- Sub-plans 0.1–0.5 completed

## Steps

### Step 1: Verify all projects are in solution

```powershell
dotnet sln Marketplace.sln list
```

Expected output (4 projects):
```
src\Aspire\Marketplace.AppHost\Marketplace.AppHost.csproj
src\Aspire\Marketplace.ServiceDefaults\Marketplace.ServiceDefaults.csproj
src\BuildingBlocks\SharedContracts\BuildingBlocks.SharedContracts.csproj
src\BuildingBlocks\Infrastructure\BuildingBlocks.Infrastructure.csproj
```

If any is missing, add it:
```powershell
dotnet sln Marketplace.sln add <path-to-missing.csproj>
```

### Step 2: Build the entire solution

```powershell
dotnet build Marketplace.sln
```

**Expected**: `Build succeeded. 0 Warning(s). 0 Error(s).`

If there are errors, fix them before proceeding. Common issues:
- Wrong `TargetFramework` → must be `net10.0`
- Missing NuGet packages → run `dotnet restore`

### Step 3: Run Aspire dashboard

```powershell
dotnet run --project src/Aspire/Marketplace.AppHost
```

**Verify in the Aspire Dashboard** (URL printed in console):
- ✅ PostgreSQL container is **Running**
- ✅ Redis container is **Running**
- ✅ RabbitMQ container is **Running**
- ✅ No error entries in the dashboard logs

### Step 4: Verify infrastructure connectivity (optional)

While AppHost is running, in a new terminal:

```powershell
# Check PostgreSQL
docker ps | Select-String "postgres"

# Check Redis
docker ps | Select-String "redis"

# Check RabbitMQ management UI (open in browser)
# Typically at http://localhost:15672 (guest/guest)
```

### Step 5: Stop and commit

Press `Ctrl+C` to stop the AppHost.

```powershell
git add -A
git commit -m "feat: Phase 0 - Foundation scaffolding

- Marketplace.sln with global.json (.NET 10)
- Marketplace.AppHost: PostgreSQL (6 DBs), Redis, RabbitMQ
- Marketplace.ServiceDefaults: OpenTelemetry, health checks, resilience
- BuildingBlocks.SharedContracts: AggregateRoot, Entity, ValueObject, IDomainEvent, IRepository, IUnitOfWork
- BuildingBlocks.Infrastructure: GlobalExceptionMiddleware, PagedResult, Result, ValidationBehavior, LoggingBehavior"
```
