# 0.4 — Create BuildingBlocks.SharedContracts

> **Ref**: [plans/04-monorepo-structure.md](../../plans/04-monorepo-structure.md) · [plans/03-clean-architecture.md](../../plans/03-clean-architecture.md) · [implementation_plan/phase-0-foundation.md](../phase-0-foundation.md)

## Goal
Create the shared contracts library with DDD base types and empty event/command folders. This library is referenced by every microservice's Domain and Application layers.

## Prerequisites
- Sub-plan 0.1 completed

## ⚠️ Rules (from architecture docs)
- **NO** EF Core or database packages allowed
- **NO** business logic
- **NO** shared domain entities
- Only interfaces, base classes, and flat message contracts

/// <summary>
/// Base class for all entities with identity.
/// </summary>
public abstract class Entity
{
    public Guid Id { get; protected init; } = Guid.NewGuid();

    public override bool Equals(object? obj) =>
        obj is Entity other && Id == other.Id;

    public override int GetHashCode() => Id.GetHashCode();
}

### Step 6: Create `AggregateRoot.cs`

File: `src/BuildingBlocks/SharedContracts/Abstractions/AggregateRoot.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Abstractions;

/// <summary>
/// Base class for aggregate roots. Collects domain events for dispatch after persistence.
/// </summary>
public abstract class AggregateRoot : Entity
{
    private readonly List<IDomainEvent> _domainEvents = [];

    public IReadOnlyList<IDomainEvent> DomainEvents => _domainEvents.AsReadOnly();

    protected void AddDomainEvent(IDomainEvent domainEvent) =>
        _domainEvents.Add(domainEvent);

    public void ClearDomainEvents() => _domainEvents.Clear();
}
```

### Step 7: Create `ValueObject.cs`

File: `src/BuildingBlocks/SharedContracts/Abstractions/ValueObject.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Abstractions;

/// <summary>
/// Base class for value objects. Equality is determined by component values.
/// </summary>
public abstract class ValueObject : IEquatable<ValueObject>
{
    protected abstract IEnumerable<object?> GetEqualityComponents();

    public bool Equals(ValueObject? other)
    {
        if (other is null || GetType() != other.GetType())
            return false;

        return GetEqualityComponents()
            .SequenceEqual(other.GetEqualityComponents());
    }

    public override bool Equals(object? obj) =>
        obj is ValueObject other && Equals(other);

    public override int GetHashCode() =>
        GetEqualityComponents()
            .Aggregate(0, (hash, component) =>
                HashCode.Combine(hash, component?.GetHashCode() ?? 0));

    public static bool operator ==(ValueObject? left, ValueObject? right) =>
        Equals(left, right);

    public static bool operator !=(ValueObject? left, ValueObject? right) =>
        !Equals(left, right);
}
```
