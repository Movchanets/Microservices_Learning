# 0.2 — Scaffold Marketplace.AppHost

> **Ref**: [plans/04-monorepo-structure.md](../../plans/04-monorepo-structure.md) · [plans/09-infrastructure-deployment.md](../../plans/09-infrastructure-deployment.md) · [implementation_plan/phase-0-foundation.md](../phase-0-foundation.md)

## Goal
Create the .NET Aspire AppHost project that orchestrates all infrastructure (PostgreSQL, Redis, RabbitMQ) and will later reference all microservices.

## Prerequisites
- Sub-plan 0.1 completed (solution + directories exist)
- .NET 10 SDK with Aspire workload installed

### Install Aspire workload (if not already):
```powershell
dotnet workload install aspire
```

## Steps

### Step 1: Create the AppHost project

```powershell
dotnet new aspire-apphost --name Marketplace.AppHost --output src/Aspire/Marketplace.AppHost
```

### Step 2: Add to solution

```powershell
dotnet sln Marketplace.sln add src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj
```

### Step 3: Add Aspire hosting NuGet packages

```powershell
cd src/Aspire/Marketplace.AppHost

dotnet add package Aspire.Hosting.PostgreSQL
dotnet add package Aspire.Hosting.Redis
dotnet add package Aspire.Hosting.RabbitMQ

cd ../../..
```

### Step 4: Replace `Program.cs` with infrastructure setup

Overwrite `src/Aspire/Marketplace.AppHost/Program.cs` with the following content:

```csharp
var builder = DistributedApplication.CreateBuilder(args);

// ──────────────────────────────────────────────
// Infrastructure Resources
// ──────────────────────────────────────────────

// PostgreSQL server + per-service databases
var postgres = builder.AddPostgres("postgres")
    .WithPgAdmin();

var identityDb  = postgres.AddDatabase("identity-db");
var catalogDb   = postgres.AddDatabase("catalog-db");
var orderingDb  = postgres.AddDatabase("ordering-db");
var inventoryDb = postgres.AddDatabase("inventory-db");
var paymentDb   = postgres.AddDatabase("payment-db");
var storeDb     = postgres.AddDatabase("store-db");

// Redis — used by Cart.API, Notification.Worker (SignalR backplane)
var redis = builder.AddRedis("redis")
    .WithRedisInsight();

// RabbitMQ — message broker for MassTransit
var messaging = builder.AddRabbitMQ("messaging")
    .WithManagementPlugin();

// ──────────────────────────────────────────────
// Microservices (to be added in later phases)
// ──────────────────────────────────────────────

// Phase 1: Identity.API  → .WithReference(identityDb).WithReference(messaging)
// Phase 1: ApiGateway    → .WithReference(redis)
// Phase 2: Catalog.API   → .WithReference(catalogDb).WithReference(messaging)
// Phase 2: Search.API    → .WithReference(messaging)
// Phase 3: Inventory.API → .WithReference(inventoryDb).WithReference(messaging)
// Phase 3: Cart.API      → .WithReference(redis).WithReference(messaging)
// Phase 4: Ordering.API  → .WithReference(orderingDb).WithReference(messaging)
// Phase 4: Payment.API   → .WithReference(paymentDb).WithReference(messaging)
// Phase 5: Notification  → .WithReference(redis).WithReference(messaging)
// Phase 6: StoreMgmt.API → .WithReference(storeDb).WithReference(messaging)
// Phase 6: Media.API     → blob storage reference
// Phase 7: Angular       → builder.AddNpmApp(...)

builder.Build().Run();
```

### Step 5: Verify the project file

Open `src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj` and confirm it contains:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <IsAspireHost>true</IsAspireHost>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Aspire.Hosting.AppHost" Version="*" />
    <PackageReference Include="Aspire.Hosting.PostgreSQL" Version="*" />
    <PackageReference Include="Aspire.Hosting.Redis" Version="*" />
    <PackageReference Include="Aspire.Hosting.RabbitMQ" Version="*" />
  </ItemGroup>

</Project>
```

> **Note**: The `Version="*"` is a placeholder. The actual versions will be resolved by NuGet. Verify the installed versions are for .NET 10.

## Verification

```powershell
# Build the AppHost
dotnet build src/Aspire/Marketplace.AppHost/Marketplace.AppHost.csproj

# Run it (Docker must be running!)
dotnet run --project src/Aspire/Marketplace.AppHost
```

After running, open the Aspire Dashboard URL printed in console (typically `https://localhost:15XXX`). Confirm you see:
- ✅ PostgreSQL container running
- ✅ Redis container running
- ✅ RabbitMQ container running (with management UI)

Press `Ctrl+C` to stop.
