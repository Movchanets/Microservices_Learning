## Step 2: Domain Layer

### `Store.cs` — Aggregate Root
```csharp
public sealed class Store : AggregateRoot
{
    public Guid Id { get; private set; }
    public string SellerId { get; private set; }    // Identity user ID
    public string Name { get; private set; }
    public string Description { get; private set; }
    public string? LogoUrl { get; private set; }
    public VerificationStatus VerificationStatus { get; private set; }
    public DateTime CreatedAt { get; private set; }
    public DateTime? VerifiedAt { get; private set; }

    // Navigation
    private readonly List<SellerProfile> _sellerProfiles = [];
    public IReadOnlyCollection<SellerProfile> SellerProfiles => _sellerProfiles.AsReadOnly();

    // Factory method
    public static Store Create(string sellerId, string name, string description) { ... }
    public void UpdateDetails(string name, string description) { ... }
    public void SetLogo(string logoUrl) { ... }
    public void Verify() { ... }      // → Verified, raises StoreVerifiedDomainEvent
    public void Reject(string reason) { ... }  // → Rejected
}
```

## Step 4: Infrastructure Layer

### `StoreDbContext`
```csharp
public sealed class StoreDbContext(DbContextOptions<StoreDbContext> options)
    : DbContext(options), IUnitOfWork
{
    public DbSet<Store> Stores => Set<Store>();
    public DbSet<SellerProfile> SellerProfiles => Set<SellerProfile>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.ApplyConfigurationsFromAssembly(typeof(StoreDbContext).Assembly);
    }
}
```

### EF Core Configurations
- `StoreConfiguration`: PK, SellerId index (unique), Name max length, VerificationStatus conversion, owned collections
- `SellerProfileConfiguration`: PK, FK to Store, Email max length

### `StoreRepository` — implements IStoreRepository
- Standard EF Core repository pattern matching Catalog/Ordering

### `DatabaseMigrationExtensions` — ApplyMigrations pattern
```csharp
public static void ApplyMigrations(this WebApplication app)
{
    using var scope = app.Services.CreateScope();
    var db = scope.ServiceProvider.GetRequiredService<StoreDbContext>();
    db.Database.Migrate();
}
```

### `DependencyInjection.cs`
```csharp
public static class DependencyInjection
{
    public static IServiceCollection AddStoreManagementInfrastructure(
        this IServiceCollection services, IConfiguration configuration)
    {
        services.AddDbContext<StoreDbContext>(options =>
            options.UseNpgsql(
                configuration.GetConnectionString("store-db"),
                npgsql => npgsql.MigrationsAssembly(typeof(StoreDbContext).Assembly.FullName)));

        services.AddScoped<IStoreRepository, StoreRepository>();
        services.AddScoped<IUnitOfWork>(sp => sp.GetRequiredService<StoreDbContext>());
        return services;
    }
}
```

## Step 5: API Layer

### `StoreEndpoints.cs`
```
POST   /api/stores              → CreateStoreCommand (Seller role)
GET    /api/stores              → ListStoresQuery (Admin)
GET    /api/stores/{id}         → GetStoreByIdQuery
GET    /api/stores/seller/{id}  → GetStoreBySellerIdQuery
PUT    /api/stores/{id}         → UpdateStoreCommand (Seller, own store)
POST   /api/stores/{id}/verify  → VerifySellerCommand (Admin)
PUT    /api/stores/{id}/logo    → SetStoreLogoCommand (Seller, own store)
```

### `Program.cs`
Follow Catalog.Ordering pattern:
1. `builder.AddServiceDefaults()`
2. `builder.Services.AddStoreManagementInfrastructure(builder.Configuration)`
3. MediatR + ValidationBehavior + LoggingBehavior
4. FluentValidation
5. MassTransit (RabbitMQ, Outbox)
6. JWT Bearer auth
7. OpenAPI
8. Middleware pipeline: `GlobalExceptionMiddleware` → `MapDefaultEndpoints` → Auth → `MapOpenApi`
9. `app.MapStoreEndpoints()`
10. `app.ApplyMigrations()` in dev
