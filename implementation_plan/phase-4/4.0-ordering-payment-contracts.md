# 4.0 — Ordering & Payment Contracts

> **Ref**: [plans/05-messaging-sagas.md](../../plans/05-messaging-sagas.md) · [plans/02-domain-decomposition.md](../../plans/02-domain-decomposition.md)

## Goal
Create the shared integration contracts for the Ordering saga and Payment service in `BuildingBlocks.SharedContracts`. These contracts define the commands and events that flow between Ordering, Payment, Inventory, and Notification services.

## Prerequisites
- BuildingBlocks.SharedContracts project exists
- `OrderItemContract` already exists in `SharedContracts/Dtos/`
- `OrderSubmittedEvent`, `ReserveInventoryCommand`, `CancelReservationCommand`, `InventoryReservedEvent`, `InventoryReservationFailedEvent`, `InventoryReleasedEvent` already exist from Phase 3

## Steps

### Step 1: Create Payment Commands

File: `src/BuildingBlocks/SharedContracts/Commands/Payment/ProcessPaymentCommand.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Commands.Payment;

public record ProcessPaymentCommand(
    Guid CorrelationId,
    Guid OrderId,
    decimal Amount,
    string BuyerId);
```

### Step 2: Create Payment Integration Events

File: `src/BuildingBlocks/SharedContracts/Events/Payment/PaymentCompletedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Payment;

public record PaymentCompletedEvent(
    Guid CorrelationId,
    Guid OrderId,
    string TransactionId);
```

File: `src/BuildingBlocks/SharedContracts/Events/Payment/PaymentFailedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Payment;

public record PaymentFailedEvent(
    Guid CorrelationId,
    Guid OrderId,
    string FailureReason);
```

### Step 3: Create Ordering Integration Events

File: `src/BuildingBlocks/SharedContracts/Events/Ordering/OrderCompletedEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Ordering;

public record OrderCompletedEvent(
    Guid CorrelationId,
    Guid OrderId,
    string BuyerId);
```

File: `src/BuildingBlocks/SharedContracts/Events/Ordering/OrderCancelledEvent.cs`
```csharp
namespace BuildingBlocks.SharedContracts.Events.Ordering;

public record OrderCancelledEvent(
    Guid CorrelationId,
    Guid OrderId,
    string BuyerId,
    string Reason);
```

