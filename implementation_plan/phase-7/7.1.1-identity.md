# 7.1.1 — Identity Integration (Frontend)

> **Ref**: [implementation_plan/phase-7-frontend.md](../phase-7-frontend.md) · [src/web/Design.md](../../src/web/Design.md)

## Goal
Implement the core Authentication service, HTTP interceptor, and initial Login/Register UI flows in the Angular application. Ensure it integrates securely with the ApiGateway BFF via Cookie-based authentication.

## Prerequisites
- `7.0.1-setup-angular.md` is complete.
- ApiGateway and Identity.API are running.

## Steps

### Step 1: Scaffold Core Layer & Install NgRx Signals

Create the core directory structure and install the required library for state management.

```powershell
cd src/web
pnpm add @ngrx/signals
pnpm dlx ng generate service core/auth/auth
pnpm dlx ng generate interceptor core/http/api
pnpm dlx ng generate guard core/auth/auth
```

### Step 2: Implement AuthStore (NgRx SignalStore)

Create `src/web/src/app/core/auth/auth.store.ts` to manage the authentication state centrally.

**Requirements:**
- State: `{ user: User | null, loading: boolean, error: string | null }`.
- Methods: `login()`, `logout()`, `register()`.
- Computed: `isAuthenticated`.

### Step 3: Implement AuthService

Modify `src/web/src/app/core/auth/auth.service.ts` to handle raw HTTP calls to the BFF.

**Requirements:**
- Use Angular `HttpClient` configured with `withCredentials: true`.
- Pass `{ withCredentials: true }` or rely on the global interceptor.

### Step 4: Implement ApiInterceptor

Modify `src/web/src/app/core/http/api.interceptor.ts`.

**Requirements:**
- Ensure `withCredentials: true` is attached to all outbound requests targeting the `/api` route.
- **CSRF Handling**: Extract `XSRF-TOKEN` from cookies (using `document.cookie` or `HttpXsrfTokenExtractor`) and attach it as the `X-XSRF-TOKEN` header for mutating requests (POST, PUT, DELETE).
- Handle 401 Unauthorized responses globally (trigger `logout` in `AuthStore`).

### Step 5: Scaffold Auth Features (UI)

Create the feature modules for Login and Register.

```powershell
pnpm dlx ng generate component features/auth/login
pnpm dlx ng generate component features/auth/register
```

**UI Requirements (per `Design.md`):**
- Use strictly Tailwind v4 classes mapped to the semantic theme.
- For form inputs and buttons, prefer `@spartan-ng` primitives.
- Use `AuthStore` to drive the UI state (loading indicators, error messages).
- Ensure all static text uses the `i18n` attribute.

### Step 6: Configure App Providers & Routing

Update `src/web/src/app/app.config.ts`:

```typescript
import { provideHttpClient, withInterceptors, withFetch, withXsrfConfiguration } from '@angular/common/http';
import { apiInterceptor } from './core/http/api.interceptor';

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(
      withFetch(), 
      withInterceptors([apiInterceptor]),
      withXsrfConfiguration({ cookieName: 'XSRF-TOKEN', headerName: 'X-XSRF-TOKEN' })
    )
  ]
};
```

Update `src/web/src/app/app.routes.ts` to include the auth features and guards.

### Step 7: Verify Auth Flow

Run the full stack:

```powershell
cd src/Aspire/Marketplace.AppHost
dotnet run
```

1. Open the Angular app and navigate to `/register`.
2. Verify browser receives secure session cookies.
3. Verify `AuthStore` reflects `isAuthenticated: true` after login.
4. Verify `X-XSRF-TOKEN` header is present in POST requests to the Gateway.

## Done When
- [x] `AuthStore` implemented using `@ngrx/signals`.
- [x] `apiInterceptor` handles `withCredentials` and `X-XSRF-TOKEN`.
- [x] Auth features use `@spartan-ng` and Tailwind v4.
- [x] Registration and login verified end-to-end through the BFF.
