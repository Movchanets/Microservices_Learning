# 7.0.1 — Setup Angular Frontend

> **Ref**: [implementation_plan/phase-7-frontend.md](../phase-7-frontend.md) · [src/web/Design.md](../../src/web/Design.md)

## Goal
Scaffold the Angular 21 application within the `src/web` directory using `pnpm`. Set up Tailwind CSS v4, `@spartan-ng`, and integrate it with the .NET Aspire AppHost.

## Prerequisites
- Node.js (v20+) installed.
- `pnpm` installed globally (`npm install -g pnpm`).
- `.NET 10` SDK installed.

## Steps

### Step 1: Scaffold the Angular Application

Navigate to the repository root and run the Angular CLI via `pnpm dlx` to create a new Angular 21 project. We use `--directory` to place it cleanly in `src/web`.

```powershell
# Run from repository root
pnpm dlx @angular/cli@21 new web-frontend `
  --directory=src/web `
  --style=css `
  --routing=true `
  --standalone=true `
  --skip-install=true `
  --skip-git=true
```

Once the files are created, run the install:

```powershell
cd src/web
pnpm install
```

### Step 2: Install Tailwind CSS v4 & Spartan-ng

Install the required dependencies for our UI layer:

```powershell
cd src/web

# Install Tailwind v4 and its dependencies
pnpm add -D tailwindcss@next @tailwindcss/postcss@next postcss

# Install Spartan-ng primitives and utils
pnpm add @spartan-ng/ui-core
pnpm add clsx tailwind-merge
```

### Step 3: Configure Tailwind CSS v4

Create the `postcss.config.js` file in `src/web/`:

```javascript
// src/web/postcss.config.js
module.exports = {
  plugins: {
    '@tailwindcss/postcss': {},
  },
}
```

Update `src/web/src/styles.css` to import the Tailwind CSS theme. Ensure dark mode configuration is defined to use the class strategy.

```css
/* src/web/src/styles.css */
@import "tailwindcss";

/*
  Configuration for dark mode and default theme variables
  (Consult src/web/Design.md for full styling guidance)
*/
@theme {
  /* Define custom Spartan / Theme variables here as needed */
}
```

### Step 4: Configure `angular.json` for i18n

Ensure `@angular/localize` is initialized:

```powershell
cd src/web
pnpm dlx ng add @angular/localize --skip-confirmation
```

Update `angular.json` to define supported locales (e.g., en-US as source, es as an option). (Follow guidelines in `Design.md`).

### Step 5: Wire up Aspire AppHost

To allow .NET Aspire to orchestrate the Angular frontend alongside the microservices, we need to add an `NpmApp` to `Marketplace.AppHost`.

Open `src/Aspire/Marketplace.AppHost/Program.cs` and add the frontend definition at the bottom before `builder.Build().Run()`:

```csharp
// Phase 7: Angular Frontend
var frontend = builder.AddNpmApp("angular", "../../web", "start")
    .WithReference(gateway) // Matches 'gateway' variable in Phase 1.5
    .WithEnvironment("PORT", "4200")
    .WithHttpEndpoint(env: "PORT");
```
*(Note: adjust relative paths to `../../web` or `../web` based on where AppHost is located relative to the root)*

Update `src/web/package.json` scripts to use `pnpm` where needed, and ensure the `"start"` script works cleanly:
```json
"scripts": {
  "start": "ng serve --port $PORT",
  ...
}
```

## Verification

```powershell
# 1. Verify angular project
cd src/web
pnpm run build

# 2. Verify Aspire Orchestration
cd ../Aspire/Marketplace.AppHost
dotnet run
```
Open the Aspire dashboard and verify the `angular` resource starts successfully and is reachable on the assigned port.
