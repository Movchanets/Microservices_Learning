### ProductModel Format (from Models.cs)
```csharp
public record ProductModel(
    string StoreName,        // "Tech Store" or "Home Store"
    string CategoryName,     // "Electronics", "Clothing", etc.
    string Name,             // Product title
    string Description,      // Product description
    decimal Price,           // Price in decimal
    string Currency,         // "USD", "UAH", etc.
    string Sku,              // Unique SKU code (e.g., "PHONE-IPHONE-15-PRO")
    string[] Tags,           // Array of tags
    string ImageUrl,         // Currently picsum.photos URLs
    int InitialStock         // Stock quantity
);
```

## Rozetka.com.ua Analysis

### Site Characteristics
- Ukrainian e-commerce marketplace (similar to Amazon)
- Dynamic JavaScript rendering (React/Vue)
- Anti-bot measures present
- Product listings with pagination
- Rich product detail pages with image galleries

### Target Categories
- Laptops: https://rozetka.com.ua/ua/notebooks/c80004/
- Smartphones: https://rozetka.com.ua/ua/mobile-phones/c80259/

### Product Data Available on Listing Pages
- Product title
- Price (in UAH)
- Product image (main)
- Product URL (for detail page)

### Product Data Available on Detail Pages
- Full description
- Multiple images (gallery)
- Specifications
- SKU/Article number

## Technical Requirements

### Anti-Bot Evasion Strategies
1. Realistic User-Agent string
2. Viewport size matching common devices
3. Random delays between actions (1-3 seconds)
4. Human-like scrolling behavior
5. Accept-Language header for Ukrainian locale

### File System Structure
```
src/Tools/Seeder.App/Data/
├── products.json            # Generated by scraper
└── Images/
    ├── {sku-slug-1}/        # e.g., laptop-asus-rog/
    │   ├── image1.jpg
    │   ├── image2.jpg
    │   └── image3.jpg
    └── {sku-slug-2}/
        └── ...
```

### Idempotency Checks
1. Load existing products.json
2. Check if product SKU already exists
3. Check if image files already exist in directory
4. Skip download/scrape if exists

## Dependencies Required
- playwright: Browser automation
- fs-extra: Enhanced file system operations

- typescript: TypeScript compiler
